# QRevise

Плагин для Paper/Spigot 1.16+, который помогает модераторам проводить проверку игроков на читы прямо на сервере.

Игрока телепортирует на отдельную точку, блокирует движение и действия, запускает таймер и даёт связаться с модератором через `/contact`. Если человек выходит с сервера или тянет время — срабатывает автобан по настройкам из конфига.

## Возможности

- Проверка через **Discord** или **AnyDesk** — два режима с разными подсказками в чате
- Таймер с боссбаром и тайтлом на экране у проверяемого
- Канал связи `/contact` между игроком и модератором (чат на проверке перенаправляется туда)
- Блокировка движения, инвентаря, дропа, телепорта и команд (whitelist настраивается)
- Автобан при выходе с проверки или по истечении времени
- Список активных проверок: `/revise list`
- API-событие `PlayerReviseStartEvent` для интеграции с другими плагинами

## Команды

| Команда | Описание |
|---------|----------|
| `/revise <ник> start <discord\|anydesk>` | Начать проверку |
| `/revise <ник> finish` | Завершить проверку |
| `/revise <ник> go` | Добавить доп. время |
| `/revise <ник> rt` | Отключить таймер (боссбар остаётся у модератора) |
| `/revise list` | Список активных проверок |
| `/contact <сообщение>` | Связь игрок ↔ модератор во время проверки |

## Права

| Permission | Описание |
|------------|----------|
| `revise.use` | Использование команд проверки |
| `revise.list` | Просмотр списка проверок |
| `revise.anydesk` | Запуск проверки через AnyDesk |
| `revise.admin` | Проверка игроков с `revise.protect` |
| `revise.protect` | Защита от вызова на проверку |
| `revise.notify` | Уведомления о выходе с проверки |

## Зависимости

- [Antirelog](https://www.spigotmc.org/resources/antirelog.64661/) — снимает PvP-режим при старте проверки

## Установка

1. Собери jar или положи готовый в `plugins/`
2. Перезапусти сервер
3. Настрой `plugins/QRevise/config.yml` — локацию спавна, время, сообщения, команды бана

## Сборка

Исходники лежат в `dev/qbit/qrevise/`. Нужен Paper/Spigot API 1.16+ и зависимость Antirelog в classpath.

## Конфиг

Основное:

- `spawn-location` — куда телепортировать игрока (`мир;x;y;z;yaw;pitch`)
- `revise-time` / `extra-time` — время проверки и продление через `/revise go`
- `revise-messages` — сообщения для discord/anydesk
- `player-leave` / `time-leave` — что делать при выходе и по таймеру
- `event-cancel` — какие действия блокировать на проверке

Все тексты поддерживают `&` цвета и hex (`&x&r&r&g&g&b&b`).
